# architecture-future_2_0

Проектная работа 11 спринта курса «Архитектура программного обеспечения: продвинутый уровень» от Яндекс.Практикума.

Кейс: компания «Будущее 2.0» - медицинский стартап, выросший в холдинг с клиниками, ИИ-сервисами для диагностики и банком с финтех-услугами. Все корпоративные данные сейчас лежат в одном DWH на SQL Server с бизнес-логикой внутри и клиентским интерфейсом на PowerBuilder, из-за чего сложная отчётность строится часами. Компания переносит IT-ландшафт в облако, строит самообслуживаемую витрину данных (без медицинских карт и историй болезни) и переходит от DWH-монолита к слабосвязанной событийной архитектуре на горизонте трёх лет.
